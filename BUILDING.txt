Surveyor's Toolbox - Forge 1.19.2 port

Target:
- Minecraft 1.19.2
- Forge 43.5.2
- Java 17
- ForgeGradle 5.1.x
- Gradle 7.5.1

Build:
  gradlew build

Run client:
  gradlew runClient

Output jar:
  build/libs/surveyors_toolbox-1.0.0.jar

This port preserves the current feature set: all survey modes, HUD labels, persistent colored chalk guides, eraser ownership/admin behavior, client/server sync, and the faint no-depth-test translucent line pass for occluded measurements.
